# What is this project?
This is an open-source web application designed for university students and educators. It combines the flexibility of personal note-taking (like Obsidian) with the power of collaboration and AI support.

- 📚 Subjects & Lectures — Teachers create subjects, add lectures, and attach resources.
- ✍️ Personal Notes — Every student gets a private space to write notes during lectures.
- 🤝 Combined-Notes — The system aggregates and synthesizes shared notes into one collaborative lecture document, reviewed by teachers/moderators.
- 🧠 AI-assisted learning — Automatically generates flashcards, quizzes, and tests to help students revise.
- 🔍 Search & organization — Full-text search across lectures and notes.
- 🌐 Web-only, open source — Runs in the browser, no paid licenses required; universities can host it themselves.

# Vision statement

The goal is to make higher education knowledge more accessible, collaborative, and student-driven. Instead of fragmented personal notes, we give students a shared “knowledge commons” per subject. The app empowers communities to study smarter together without relying on expensive commercial tools.

# Audience

- Students — Write and organize your own notes, practice with flashcards, and benefit from collaborative giga-notes.
- Educators/Admins — Set up subjects, provide official resources, and curate AI-generated material.
- Contributors — Join the project! Help build features, improve AI pipelines, or translate the app for your university.

# Why open source?

- Universities shouldn’t have to pay subscription fees for core study tools.
- Open code means transparency (important when AI is involved).
- Contributions from the community can make the tool better for everyone.
